# 用户指定的圈 X 扩展功能清单（2026-10-12）

主配置 [`quantumultx.conf`](quantumultx.conf) 已登记 13 项可直接下载的重写资源，默认关闭。原有节点、策略组、分流保持不变。`enabled=false` 代表尚未在手机上生效；需在圈 X「引用资源→重写」中按需打开。每次只打开一个并测试，再决定是否保留。

- B 站已有广告综合重写；Global/Enhanced/ADBlock 可能与它匹配同一请求，须单独测试，尤其不能认为多开就能去更多广告。
- DualSubs Universal 与各平台单独规则可能重叠；Netflix 证书固定等限制仍由上游决定。
- 苹果三项只改对应服务的请求，不改变 iOS 系统更新的现有策略；iOS 27.2 Beta 上均未实测。
- 拼多多链接混有分流和重写语法，不能直接放进「重写资源」。知乎链接只是脚本目录；YouTube 画中画和 Adblock4limbo 给的是项目主页，尚无选定的独立资源文件。
- 以下定时监控脚本未启用：多数需要用户自己的监控目标、Cookie、API Token 或旧接口适配。不要把凭据写入公开仓库。第 30/31 项是同一个脚本。
- Google 验证码规则另由本仓库 [`qx-google-captcha.conf`](qx-google-captcha.conf) 提供；异常时尝试其他代理策略，不能保证通过验证码。

下面保留用户提供的完整需求清单及原链接，便于逐项核验。清单中的“源码可读取”不代表在当前手机上有效。
