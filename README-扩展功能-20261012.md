# 圈 X 扩展：仓库文件与使用说明（2026-10-12）

本次已把下面的规则、主要处理脚本、设置文件写入本仓库，并在 `quantumultx.conf` 中启用。主配置共 20 个重写资源，包含原有功能；不再使用上一版“13 项默认关闭的上游链接”接入方式。监控、签到、价格通知等定时任务按用户要求暂不实施。

## 已在用圈 X：这样更新

1. 先在圈 X 备份当前配置。
2. 打开本仓库 [重写资源替换段](https://raw.githubusercontent.com/woziji159/Quantunmult/refs/heads/main/ext-install-rewrite-remote.txt)，复制全文。
3. 在圈 X 编辑当前配置，用它**替换整个 `[rewrite_remote]` 段**，到下一个 `[段名]` 之前为止。不要把两个 `[rewrite_remote]` 段叠加，也不要粘进单条重写的编辑框。
4. 保存后，在“重写规则→引用资源”点“全部更新”。保持重写、MitM 开启及证书完全信任。
5. 退出要测试的 App 后重开；网页重新加载。旧缓存不会因下载规则立即消失。

这样会保留手机中的节点、节点订阅、手动选择、MitM 证书及其他个人设置。完整配置入口仍是 [quantumultx.conf](https://raw.githubusercontent.com/woziji159/Quantunmult/refs/heads/main/quantumultx.conf)，但公开配置不含你的私有节点和证书，已有手机配置优先只替换上面的资源段。只刷新旧资源不会自动增加本次新资源。

## 调整设置

保持圈 X 开启，用 iPhone Safari 打开：

- B站界面、跨区及净化设置：<https://app.bilibili.com/settings/>
- DualSubs 字幕设置：<https://dualsubs.github.io/settings/>
- BoxJS：<http://boxjs.com>。在订阅管理添加下面的链接，可调整苹果天气、地图、定位以及字幕参数：

```
https://raw.githubusercontent.com/woziji159/Quantunmult/refs/heads/main/ext-settings.boxjs.json
```

这些设置页由本仓库重写响应提供。页面加载失败时，先确认对应重写资源已下载、打开的是以上准确地址。API Key 等私人参数只在手机本地填写，不要写到公开仓库。

## 整合和检查记录

- 原主配置除 `[rewrite_remote]` 外保持不变；节点分组、分流、苹果邮箱策略、iOS 更新 DIRECT/REJECT 行为均未改动。
- 使用新的 `qx-rewrite-app-ads-extended.conf` 和 `qx-rewrite-web-ads-extended.conf`，删掉与新资源重复的 B站、YouTube、Google、知乎处理入口。原资源文件保留给旧配置使用。
- Google、YouTube 的串联脚本有异常及超时回退；B站 Enhanced 后继续清理底栏。
- 17 项本地模拟测试通过：规则依赖、9 个共用请求匹配、底栏清理、二进制响应、Google 回退、拼多多和知乎响应。1,898 条 ICU 正则编译检查通过。见 `ext-integration-validation.json`、`ext-icu-validation.json`。
- **尚未在你的 iPhone、当前 App 或 iOS Beta 实测。** 以上检查不能证明所有广告消失、所有字幕服务可用或所有网页布局兼容；发现具体异常可关闭对应资源恢复。
- 镜像是 2026-10-12 获取并整合的快照；仓库不会凭空跟随上游更新。圈 X 每日更新只拉取本仓库的新提交。
