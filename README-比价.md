# 京东／淘宝比价入口

在 iPhone 的京东或淘宝商品网页右下角点“比价”，可分别打开历史价查询和跨平台当前价搜索。两项服务均为第三方页面，商品匹配与显示价格以其页面为准，不能代表结算实付价。历史价页面可能要求真人验证。

此功能只修改 HTML 商品页，不修改京东、淘宝原生 App 的接口。京东 App 内嵌的 `in.m.jd.com/product/graphext/` 页面也已匹配，但只有该页面返回 HTML 时才会出现入口；淘宝 App 的原生商品页不保证出现。若网页已经由其他重写规则截断，入口也不会显示。

配置由主文件 `quantumultx.conf` 的“京东淘宝比价”重写资源启用。圈 X 需开启重写和 MitM，并信任自己的证书。脚本没有读取登录 Cookie，也不会替用户下单。

历史价入口：[商品历史价格查询](https://www.hisprice.com/)；跨平台入口：[慢慢买搜索](https://s.manmanbuy.com/pc/search/result)。本脚本仅生成跳转链接，不接入未公开的价格 API。
